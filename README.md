# 有休ノート

年次有給休暇の付与・取得・失効を自分で管理するための、1 ファイルで動くブラウザアプリです。iPhone のホーム画面に追加して、1 台で使うことを想定しています。

**https://ytkhs.github.io/yukyu-note/**

- サーバーなし・ログインなし。データはその端末のブラウザ内にだけ保存されます
- バックアップは JSON ファイルとして iCloud Drive などに手動で保存します

## できること

- もらった有休の登録（日数・もらった日・期限）
- 取得の記録（全休・半休、メモ付き）と、記録の編集・削除
- 残日数、次に失効する日数と日付、取得済み、失効済みの表示
- もらった有休ごとの消化状況（有休の内訳）と、期限が 60 日以内に迫った分の強調
- 期限が終わった有休と去年以前の取得履歴は折りたたんで表示（データは消えません）。期限が終わった有休には何%使えたかを表示します
- 年 5 日の取得義務の進捗表示
- バックアップの保存と復元。前回の保存から 14 日以上たつと画面上部に注意が出ます

## iPhone での使い方

1. Safari で上の URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. 以降はホーム画面のアイコンから開く

Safari のタブで開いた場合とホーム画面から開いた場合では、データの保存場所が別々になり共有されません。また Safari のタブで使っていると、しばらく開かなかったサイトのデータを Safari が削除することがあります。必ずホーム画面から使ってください。

### バックアップ

- **保存:**「💾 バックアップを保存」→ 共有シートの「"ファイル"に保存」→ iCloud Drive の任意のフォルダを選ぶ。ファイル名は `yukyu-note-YYYY-MM-DD.json` です
- **復元:**「📂 バックアップから復元」→ 保存した JSON を選ぶ。端末内のデータはファイルの内容で丸ごと置き換わります（置き換える前に確認が出ます）

データは端末の中にしかないため、機種変更や Safari のデータ消去をすると消えます。定期的に保存してください。機種変更のときは、新しい端末で復元すれば引き継げます。

PC のブラウザでは、保存を押すと JSON がダウンロードされます。

## 計算のルール

画面では分かりやすさのため「付与」を「もらった有休」と表記していますが、以下では法律上の用語の「付与」を使います。

| 項目 | ルール |
|---|---|
| 期限の初期値 | 付与日から 2 年後の前日（労働基準法の時効 2 年）。手で変更できます |
| 消化の順番 | 取得日の時点で有効な付与のうち、期限が近いものから引き当てる（繰越分が先に減る） |
| 残り | 今日の時点で有効な付与の残日数の合計。未来の日付で記録した取得予定も差し引いた値です |
| 取得済み | いま有効な付与から、今日までに取得した日数。未来の日付の予定は「ほかに予定」として別に表示します。有効な付与の日数 = 取得済み + 予定 + 残り になります |
| 取得率（取得済みの横の %） | 取得済み ÷ いま有効な付与の日数の合計 |
| 失効済み | 期限が過ぎた付与で、使い切れなかった日数の合計 |
| 残日数不足 | 取得日の時点で有効な付与の残りが足りない記録に付く印。足りなかった分は「取得済み」や年 5 日の取得義務に数えません |
| 年 5 日の取得義務 | 10 日以上の付与について、付与日から 1 年間に取得した日数を数える。今日を含む期間を表示し、該当がなければ直近に終わった期間の結果を表示します。半休は 0.5 日として数え、期間内の予定は「予定を含めると」として別に表示します |

同じ日に記録できるのは合計 1 日分（全休 1 回、または半休 2 回）までです。

## 既知の制約

- 付与は編集できません。間違えたときは削除して登録し直してください
- 付与日が 1 年以内に 2 回ある場合（入社半年後の付与のあと、4 月 1 日の一斉付与に切り替わる場合など）の、年 5 日の取得義務の特例（期間をまとめて按分する扱い）には対応していない
- 繰越分と新しい付与分は、別々の付与として登録してください。まとめて 1 件にすると、消化の順番や年 5 日の取得義務の判定（10 日以上かどうか）がずれます
- 時間単位の有休、会社独自の休暇（特別休暇など）、土日・祝日の判定には対応していない

## データ形式

ブラウザの `localStorage` に、キー `pto-tracker-v1` で次の JSON を保存しています。バックアップのファイルも同じ形式です。

```json
{
  "grants": [
    { "days": 10, "start": "2026-04-01", "end": "2028-03-31" }
  ],
  "uses": [
    { "date": "2026-05-01", "days": 1, "memo": "温泉旅行" },
    { "date": "2026-07-10", "days": 0.5, "memo": "" }
  ]
}
```

- 日付はすべて `YYYY-MM-DD` の文字列です
- `uses[].days` は `1`（全休）か `0.5`（半休）です

前回バックアップした日は、別のキー `pto-tracker-v1-exported` に保存しています。

## 開発

ビルドや依存パッケージはありません。`index.html` に HTML・CSS・JavaScript をすべてまとめています。

ローカルでは `index.html` をブラウザで開けば動きます。iPhone の実機で確認するときは、同じネットワーク内でサーバーを立てて、iPhone から `http://<PCのIPアドレス>:8000/` を開きます。

```
python3 -m http.server 8000
```

`main` ブランチに push すると、GitHub Pages に自動で反映されます（数分かかります）。

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `apple-touch-icon.png` | ホーム画面のアイコン（180×180） |
| `.nojekyll` | GitHub Pages で Jekyll の変換を無効にする |
